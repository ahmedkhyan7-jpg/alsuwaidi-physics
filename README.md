# alsuwaidi-physics
منصة السويدي التعليمية للفيزياء، تجمع المنهج اليمني للصفوف الأول والثاني والثالث الثانوي في تجربة تعليمية متكاملة، تشمل الشروحات المصورة والفيديوهات التعليمية والملخصات والكتب والاختبارات الإلكترونية، بالإضافة إلى مختبر تفاعلي ثلاثي الأبعاد لمحاكاة التجارب والقوانين الفيزيائية، بهدف تبسيط العلوم وتطوير مهارات الطلاب.
